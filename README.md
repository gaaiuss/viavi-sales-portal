# VIAVI Sales Portal

A Django based web application to catalog VIAVI Office Equipments.

## Project Structure

Apps:

- home: dashboard, app options, search bar, menu
- assets: equipments and accessories
- inventory: assets + locations + colaborators
- colaborators: viavi employees
- locations: storages, clients, cabinet, drawer
- notifications: comments, assets updates
- departments: sales, import, it
